# feeeeel
A mod for [Stonemachia](https://store.steampowered.com/app/2982610/Stonemachia/) which adds controller vibration to the steps of large creatures based on camera shake

just an extremely simple script for now and only has preset duration values

will likely be updated in the future as the script only has 5 camera shake in it since I'm still at the beginning of the game and I will see more in the future (I couldn't bear to play the game without this)

also I'm not sure how to distribute mods for ue4ss so I will figure that out
